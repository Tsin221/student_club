# S12：帖子点赞 — 实现说明

## 文档信息

- **切片 ID**：S12
- **用户结果**：当前在社成员可以点赞或取消点赞正常帖子，并看到实时点赞数和本人点赞状态
- **依赖**：S10
- **状态**：已验收

## 实现范围

### 新增模型

| 模型 | 表名 | 说明 |
|---|---|---|
| `PostLike` | `post_like` | 帖子点赞关系：关联用户和帖子，唯一约束保证同用户同帖只有一条 |

**字段设计：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | `BigAutoField` | 主键 |
| `user` | `FK → User` | 点赞用户，`CASCADE`，`related_name="liked_posts"` |
| `post` | `FK → Post` | 被点赞帖子，`CASCADE`，`related_name="post_likes"` |
| `created_at` | `DateTimeField(auto_now_add)` | 点赞时间 |

**约束与索引：**

- `UniqueConstraint(fields=["user", "post"])` — 同一用户对同一帖子最多保留一条点赞关系
- `post_likes` 反向关联用于 `serialize_post` 中实时计算 `like_count` 和 `liked_by_me`

### 新增接口（1 条路由，2 种方法）

| 接口 | 调用者 | 说明 |
|---|---|---|
| `POST /api/posts/{post_id}/like` | 在社成员 | 点赞帖子，重复点赞返回 `DUPLICATE_LIKE` |
| `DELETE /api/posts/{post_id}/like` | 已点赞成员 | 取消点赞，无记录时返回 `LIKE_NOT_FOUND` |

**共用守卫** `_require_post_accessible(request, post_id)`：
1. 帖子存在（404 `RESOURCE_NOT_FOUND`）
2. 帖子未删除（409 `POST_DELETED`）
3. 用户为帖子所属社团当前在社成员（`require_club_member`）

**错误码汇总：**

| 错误码 | 状态码 | 触发条件 |
|---|---|---|
| `RESOURCE_NOT_FOUND` | 404 | 帖子不存在 |
| `POST_DELETED` | 409 | 帖子已删除 |
| `NOT_CLUB_MEMBER` | 403 | 不是社团成员 |
| `MEMBERSHIP_INACTIVE` | 403 | 成员关系已退出/已移除 |
| `CLUB_CANCELLED` | 409 | 社团已注销 |
| `DUPLICATE_LIKE` | 409 | 重复点赞（POST like） |
| `LIKE_NOT_FOUND` | 404 | 取消不存在的点赞（DELETE like） |
| `UNAUTHENTICATED` | 401 | 未登录 |

### 序列化器变更

`serialize_post` 中 `like_count` 和 `liked_by_me` 从预置占位改为实时计算：

```python
like_count = post.post_likes.count()
liked_by_me = (
    current_user_id is not None
    and post.post_likes.filter(user_id=current_user_id).exists()
)
```

### 新增前端 API

| 函数 | 方法 | 路径 | 返回 |
|---|---|---|---|
| `likePost(postId)` | POST | `/api/posts/{postId}/like` | `Post`（含更新后 like_count/liked_by_me） |
| `unlikePost(postId)` | DELETE | `/api/posts/{postId}/like` | `Post`（含更新后 like_count/liked_by_me） |

### 前端 UI 变更

**StudentClubDetailView.vue** — 每个帖子卡片内容下方新增点赞按钮：

- 未点赞：🤍 + 计数（`default` 按钮样式）
- 已点赞：❤️ + 计数（`danger` 按钮样式）
- 点击时显示 loading 动画，防止重复点击
- 成功后直接替换 posts 列表中对应项，实时反映 like_count/liked_by_me 变化
- 失败时通过 ElMessage 显示后端错误信息

### 后端测试（21 项）

**POST /api/posts/{post_id}/like（11 项）：**
1. 在社成员成功点赞返回 201 + like_count=1 + liked_by_me=true
2. 多用户点赞后 like_count 正确累加
3. 已点赞用户看到 liked_by_me=true，未点赞用户看到 false
4. 重复点赞返回 409 DUPLICATE_LIKE
5. 已删除帖子不能点赞返回 409 POST_DELETED
6. 非成员不能点赞返回 403 NOT_CLUB_MEMBER
7. 已退出成员不能点赞返回 403 MEMBERSHIP_INACTIVE
8. 已注销社团的帖子不能点赞返回 409 CLUB_CANCELLED
9. 未登录不能点赞返回 401 UNAUTHENTICATED
10. 不存在帖子返回 404 RESOURCE_NOT_FOUND
11. 帖子列表中 like_count/liked_by_me 在点赞后正确更新

**DELETE /api/posts/{post_id}/like（9 项）：**
12. 取消点赞成功返回 200 + like_count=0 + liked_by_me=false
13. 多人点赞后一人取消，计数正确减少
14. 取消不存在的点赞返回 404 LIKE_NOT_FOUND
15. 已删除帖子不能取消点赞返回 409 POST_DELETED
16. 非成员不能取消点赞返回 403
17. 已退出成员不能取消点赞返回 403 MEMBERSHIP_INACTIVE
18. 已注销社团不能取消点赞返回 409 CLUB_CANCELLED
19. 未登录不能取消点赞返回 401 UNAUTHENTICATED
20. 取消点赞后可以再次点赞

**其他（1 项）：**
21. 不支持的 HTTP 方法返回 405
