## 2. S05 的目标

S05 在 S04 的基础上增加社团和成员管理的完整能力：

1. **管理员**可修改社团信息（名称/类别/简介）、注销社团、增删负责人、查看全量成员关系。
2. **负责人**可修改本人负责社团的简介，查看当前在社成员列表（含手机号）。
3. 建立负责人"当前社团上下文"机制——通过 URL clubId 实现路由、数据和 API 同步。

## 3. 已完成的内容

### 3.1 后端新增

#### 守卫函数

- `require_leader_of_club(request, club_id)`：依次校验认证、学生、账号正常、社团存在且正常、成员在社且负责人。
- `_count_effective_leaders(club)`：统计正常社团有效负责人数（排除已停用）。

#### 辅助函数

- `_parse_json_body(request)`：安全解析 JSON。
- `_parse_club_patch_body(request, allowed_fields)`：自动检测 multipart/JSON，手动解析 PATCH multipart。

#### 7 个新接口

| 方法与路径 | 用途 | 关键行为 |
|---|---|---|
| `PATCH /api/admin/clubs/{id}` | 管理员修改社团 | name/category/introduction 可选 |
| `POST /api/admin/clubs/{id}/cancel` | 管理员注销社团 | CLUB_ALREADY_CANCELLED(409) |
| `PATCH /api/leader/clubs/{id}` | 负责人修改简介 | 只允许 introduction |
| `GET /api/admin/memberships` | 管理员全量成员关系 | 分页，含所有状态 |
| `GET /api/leader/clubs/{id}/members` | 查看在社成员 | 管理员+负责人均可调用，含手机号 |
| `POST /api/admin/clubs/{id}/leaders` | 管理员提升负责人 | 校验在社+普通成员+账号正常 |
| `DELETE /api/admin/clubs/{id}/leaders/{mid}` | 管理员降级负责人 | 最后有效负责人保护 |
