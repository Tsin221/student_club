# S13：社团评价 — 实现说明

## 文档信息

- **切片 ID**：S13
- **用户结果**：当前在社成员提交、查看和修改本人评价；管理员查看全部评价记录
- **依赖**：S07
- **状态**：已验收

## 实现范围

### 新增模型

| 模型 | 表名 | 说明 |
|---|---|---|
| `ClubEvaluation` | `club_evaluation` | 社团评价：关联用户、社团、成员关系，评分 1-5 星，可选文字评价 |

**字段设计：**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | `BigAutoField` | 主键 |
| `user` | `FK → User` | 评价用户，`PROTECT` |
| `club` | `FK → Club` | 被评价社团，`PROTECT` |
| `membership` | `OneToOneField → ClubMembership` | 对应成员关系，`PROTECT`，一行一条评价 |
| `rating` | `PositiveSmallIntegerField` | 一至五星 |
| `comment` | `TextField(null=True)` | 可选文字评价 |

**约束与索引：**

- `membership` 为 OneToOneField，确保一条成员关系最多一条评价
- `user_id` 和 `club_id` 各自建立普通索引
- 无 `created_at`/`updated_at`（按阶段一设计）
- 无审核状态、匿名标志或删除状态

### 新增接口（4 个）

| 接口 | 调用者 | 说明 |
|---|---|---|
| `POST /api/clubs/{club_id}/evaluations` | 在社成员 | 提交评价（1-5 星 + 可选文字） |
| `GET /api/me/evaluations` | 学生 | 查看本人全部评价（含历史） |
| `PATCH /api/me/evaluations/{evaluation_id}` | 评价本人 | 修改评分或文字，仍需在社 |
| `GET /api/admin/evaluations` | 管理员 | 分页查看全部评价（只读） |

## 关键实现决策

### 1. membership 使用 OneToOneField

Django 提示 `ForeignKey(unique=True)` 更适合使用 `OneToOneField`，且业务语义"一条成员关系最多一条评价"正是一对一关系，因此采用 `OneToOneField` 并在迁移中反映。

### 2. 评价修改权限链

修改评价需同时满足：评价本人 + 账号正常 + 社团正常 + 仍为在社成员。退出/移除后只能查看历史，不能修改。

### 3. 评分校验

后端严格校验评分必须为整数且 1-5，前端使用 `el-rate` 组件天然限制范围，双重保障。

### 4. 管理员只读

管理员评价页面使用表格 + 分页展示，不提供任何修改、删除、审核或统计功能，符合阶段一设计。

### 5. 社团详情页内嵌评价

在社团详情页加载时同时查询本人对该社团的评价，提供「评价社团」或「修改评价」入口，弹窗内统一处理创建和修改。

## 错误码

| 错误码 | HTTP 状态 | 场景 |
|---|---|---|
| `INVALID_RATING` | 400 | 评分缺失、非整数或不在 1-5 |
| `DUPLICATE_EVALUATION` | 409 | 同一成员关系重复提交 |
| `NOT_EVALUATION_OWNER` | 403 | 非本人尝试修改 |
| `NOT_CLUB_MEMBER` | 403 | 非社团成员提交 |
| `MEMBERSHIP_INACTIVE` | 403 | 已退出或已移除 |
| `CLUB_CANCELLED` | 409 | 社团已注销 |
