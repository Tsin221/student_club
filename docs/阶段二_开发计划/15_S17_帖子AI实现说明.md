# S17：帖子 AI 实现说明

## 用户结果

有权查看正常帖子的当前在社成员可以对帖子执行三种 AI 操作：总结、提取主要观点、基于当前帖子内容问答。

## 涉及接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/posts/{post_id}/ai` | 对帖子进行 AI 操作 |

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `operation` | string | 是 | 操作类型：`总结`、`提取主要观点`、`问答` |
| `question` | string | 仅 `问答` 必填 | 要问的问题 |

### 成功响应

```json
{
  "code": "SUCCESS",
  "message": "AI 回答生成成功",
  "data": {
    "answer": "AI 生成的回答文本",
    "truncated": false
  }
}
```

截断时额外包含 `warning` 字段：
```json
{
  "answer": "...",
  "truncated": true,
  "warning": "内容较长，本次回答可能未包含全部回复"
}

```

### 错误码

| HTTP | 错误码 | 说明 |
|---|---|---|
| 422 | `INVALID_AI_OPERATION` | operation 不在白名单中 |
| 422 | `QUESTION_REQUIRED` | 问答操作未提供问题 |
| 422 | `VALIDATION_ERROR` | 非问答操作携带了额外输入 |
| 404 | `RESOURCE_NOT_FOUND` | 帖子不存在 |
| 409 | `POST_DELETED` | 帖子已删除 |
| 409 | `CLUB_CANCELLED` | 社团已注销 |
| 403 | `NOT_CLUB_MEMBER` | 非社团成员 |
| 403 | `MEMBERSHIP_INACTIVE` | 当前成员关系已退出或已移除 |
| 403 | `ACCOUNT_DISABLED` | 账号已停用 |
| 503 | `DEEPSEEK_CALL_FAILED` | DeepSeek API 调用失败 |

## 涉及页面

- `/student/clubs/:id`（StudentClubDetailView）：每个帖子卡片新增「AI」按钮，点击弹出 AI 对话框

## 实现要点

### 后端

1. **DeepSeek 配置**：密钥、模型和参数仅在 `code/.env` 中配置，不暴露给前端。
   - `DEEPSEEK_API_URL`：API 地址（默认 `https://api.deepseek.com/v1/chat/completions`）
   - `DEEPSEEK_API_KEY`：API 密钥
   - `DEEPSEEK_MODEL`：模型名称（默认 `deepseek-chat`）
   - `AI_MAX_CONTENT_CHARS`：内容截断阈值（默认 8000）

2. **权限校验**：
   - 通过 `require_club_member` 校验账号正常、社团正常、在社成员
   - 额外检查帖子状态，已删除帖子拒绝 AI 操作

3. **内容收集**：
   - 读取当前帖子标题和正文
   - 读取所有正常状态的回复
   - 超长内容按 `AI_MAX_CONTENT_CHARS` 截断，返回 `truncated=true` 和 warning

4. **AI 调用**：
   - 使用 `urllib.request` 标准库调用 DeepSeek API（无需额外依赖）
   - 构造 system prompt 限制 AI 只能基于帖子内容回答
   - API 调用失败返回 `DEEPSEEK_CALL_FAILED`，不影响帖子数据

5. **不持久化**：不保存 AI 历史、不创建新数据库表

### 前端

1. **类型定义**：`types/club.ts` 新增 `AiOperation`、`PostAiInput`、`PostAiResponse`
2. **API 函数**：`api/clubs.ts` 新增 `postAi()` 函数及类型守卫
3. **UI**：`StudentClubDetailView.vue`
   - 帖子操作栏新增「AI」按钮
   - 弹出对话框：操作选择（总结/提取主要观点/问答）、问答时显示问题输入框
   - AI 回答区域：显示回答文本，截断时显示警告标签
   - 支持重新生成
