# S07：入社申请、审核、成员创建与通知 — 实现说明

## 文档信息

- **切片 ID**：S07
- **用户结果**：学生申请入社，负责人审核并生成成员和通知
- **依赖**：S06
- **状态**：已验收

## 实现范围

### 新增模型

| 模型 | 表名 | 说明 |
|---|---|---|
| `JoinApplication` | `join_application` | 入社申请：保存申请人快照、申请理由、状态 |
| `Notification` | `notification` | 站内通知：保存接收人、通知类型、展示文字 |

### 新增接口（7 个）

| 接口 | 调用者 | 说明 |
|---|---|---|
| `POST /api/recruitments/{id}/applications` | 学生 | 提交入社申请 |
| `GET /api/me/join-applications` | 学生 | 查看本人全部申请（分页） |
| `GET /api/leader/clubs/{id}/join-applications` | 负责人 | 查看本社团申请（分页） |
| `POST /api/leader/join-applications/{id}/approve` | 负责人 | 通过申请（事务：创建成员+通知） |
| `POST /api/leader/join-applications/{id}/reject` | 负责人 | 拒绝申请（事务：通知） |
| `GET /api/admin/join-applications` | 管理员 | 查看全量申请（只读） |
| `GET /api/me/notifications` | 学生 | 查看本人通知 |

### 更新既有代码

1. **`compute_recruitment_status`**：`approved_count` 从硬编码 `0` 改为实时查询
2. **`_leader_update_recruitment`**：容量调整时校验 `capacity >= approved_count`

### 新增页面

| 页面 | 路由 | 说明 |
|---|---|---|
| 社团详情页申请弹窗 | `/student/clubs/:id` | 在"进行中"招新卡片上增加"申请加入"按钮+弹窗 |
| 我的申请 | `/student/applications` | 展示本人全部申请列表及状态 |
| 负责人审核申请 | `/leader/clubs/:id/applications` | 展示本社团申请，待审核可操作通过/拒绝 |
| 我的通知 | `/student/notifications` | 展示本人通知列表 |
| 管理员查看申请 | `/admin/applications` | 管理员查看全量申请记录（只读，分页） |
