## 2. S03 的目标

S03 建立管理员用户管理路径，使系统管理员可以：

1. 通过受控命令创建管理员账号（`manage.py create_admin`）。
2. 使用管理员账号登录后自动进入 `/admin/users`。
3. 在 `/admin/users` 查看全部学生账号的分页列表。
4. 为指定学生重置密码，重置后旧密码失效。

本切片同时做了一个重要的架构决策：移除了 CSRF 防护（详见 `S03_CSRF移除决策记录.md`）。

## 3. 已完成的内容

### 3.1 管理员创建命令

新增 Django management command：

```powershell
uv run python manage.py create_admin --username admin --password "Admin123!@#"
```

命令逻辑：
- 校验用户名不重复。
- 使用 Django 默认密码校验器检查密码强度。
- 创建 `platform_role=system_admin, account_status=active` 的用户。
- 不提供公开管理员注册接口。

### 3.2 后端管理员接口

新增两个接口：

| 方法与路径 | 用途 | 关键行为 |
|---|---|---|
| `GET /api/admin/users` | 分页查看学生列表 | 只返回学生（不含管理员账号）；支持 `page`/`page_size`；不返回密码哈希 |
| `POST /api/admin/users/{user_id}/reset-password` | 重置学生密码 | 校验目标为学生在；使用 Django 密码强度校验；响应仅返回 `user_id` |

权限校验：
- 未登录 → `UNAUTHENTICATED`（401）
- 平台角色非管理员 → `FORBIDDEN`（403）
- 重置目标非学生 → `NOT_STUDENT_USER`（422）
- 目标不存在 → `RESOURCE_NOT_FOUND`（404）

### 3.3 前端管理员页面

新增路由 `/admin/users`，对应 `AdminUsersView.vue`：

- 页面加载时调用 `GET /api/admin/users` 获取学生列表。
- 表格展示：ID、用户名、姓名、手机号、专业班级、年级、状态（正常/已停用）、注册时间。
- 支持 Element Plus 分页组件（`page`、`page_size`、`total`）。
- 每行提供"重置密码"操作按钮，弹出对话框输入新密码。
- 重置成功后显示消息提示，对话框关闭。
- 空列表显示 `el-empty` 空状态。
- 加载中显示 `v-loading`。
- 未登录 → 跳转 `/login?reason=session`。
- 非管理员 → 跳转 `/login`。

### 3.4 登录角色分流

修改了登录流程，按 `platform_role` 自动跳转：

| 登录用户 | 跳转目标 |
|---|---|
| 学生（`student`） | `/student` |
| 系统管理员（`system_admin`） | `/admin/users` |

同时更新了 `useStudentAuthRedirect`，已登录的管理员访问 `/login` 时自动重定向到 `/admin/users`。

### 3.5 CSRF 移除

详见独立决策记录 `S03_CSRF移除决策记录.md`。核心变更：

- 移除 `CsrfViewMiddleware` 和所有 `CSRF_*` 配置。
- 移除 `GET /api/auth/csrf` 接口。
- 前端 `auth.ts` 简化为 `postJson()` / `patchJson()` 直接请求，不再初始化 CSRF。

## 8. 关键决定及原因

### 8.1 移除 CSRF

详见 `S03_CSRF移除决策记录.md`。核心原因：本地毕业设计项目无实际 CSRF 威胁，排查成本过高。

### 8.2 管理员登录后直接进入 `/admin/users`

S03 只实现了一个管理员页面，没有单独的管理员工作台首页。后续切片如需更多管理员页面再扩展。

### 8.3 管理员账号通过命令创建

不提供公开注册接口，管理员账号由受控的 Django management command 创建。

### 8.4 停用/恢复延后至 S20

停用学生账号需要检查最后负责人保护（依赖社团和成员关系），属于 S05 之后的逻辑，不在本切片范围。

## 9. 已知限制

1. Element Plus 全量引入仍有包体积警告。
2. 管理员没有独立的"工作台首页"，`/admin/users` 当前是唯一的管理员页面。
3. 停用/恢复学生账号在 S20 实现。
