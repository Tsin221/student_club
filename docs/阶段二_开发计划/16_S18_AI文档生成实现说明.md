# S18：AI 文档生成 —— 实现说明

## 文档信息

- **切片 ID**：S18
- **用户结果**：负责人为本人负责的正常社团生成公告、招新文案或社团介绍纯文本草稿
- **依赖**：S05（社团负责人上下文管理）
- **涉及接口**：`POST /api/leader/clubs/{club_id}/ai-documents`
- **涉及页面**：`/leader/clubs/{clubId}/ai-documents`

## 1. 实现目标

为社团负责人提供 AI 文档辅助生成功能，可生成三种类型的纯文本草稿：
- 社团公告
- 招新文案
- 社团介绍

生成结果不自动保存或发布，不持久化生成历史，支持重新生成。

## 2. 依赖的阶段一规则

- 只有目标正常社团当前有效负责人可以调用
- 只允许三种已确认文档类型
- 服务端自动补充当前社团名称和简介，不读取其他社团数据
- 返回纯文本草稿，不自动发布或覆盖业务内容
- 不保存输入、草稿或生成历史，不新增 AI 业务表
- DeepSeek 密钥、模型和参数只在后端环境配置

## 3. 涉及的数据表

不新增数据表（每次调用独立，不持久化）。

## 4. API 说明

### `POST /api/leader/clubs/{club_id}/ai-documents`

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `document_type` | string | 是 | `社团公告`、`招新文案`、`社团介绍` 之一 |
| `title_or_topic` | string | 否 | 标题/主题 |
| `main_content` | string | 否 | 主要内容 |
| `audience` | string | 否 | 面向对象 |
| `time` | string | 否 | 时间 |
| `location` | string | 否 | 地点 |
| `contact` | string | 否 | 联系方式 |
| `expected_length` | string | 否 | 期望字数 |
| `style` | string | 否 | 文风 |
| `additional_requirements` | string | 否 | 其他补充要求 |

**成功响应**：

```json
{
  "code": "SUCCESS",
  "message": "AI 文档草稿生成成功",
  "data": {
    "draft": "生成的纯文本草稿"
  }
}
```

**错误码**：

| 错误码 | HTTP 状态码 | 说明 |
|---|---|---|
| `INVALID_DOCUMENT_TYPE` | 422 | 文档类型无效或缺失 |
| `NOT_CLUB_LEADER` | 403 | 不是目标社团当前有效负责人 |
| `CLUB_CANCELLED` | 409 | 社团已注销 |
| `DEEPSEEK_CALL_FAILED` | 502 | DeepSeek API 调用失败 |

## 5. 页面说明

### `/leader/clubs/{clubId}/ai-documents`（LeaderAiDocumentsView）

- **表单区**：文档类型下拉（必填）、标题/主题、主要内容、面向对象、时间、地点、联系方式、期望字数、文风、其他要求（均为可选）
- **操作按钮**：生成草稿/重新生成（带 loading）
- **结果展示区**：纯文本草稿显示，支持复制到剪贴板
- **错误处理**：DEEPSEEK_CALL_FAILED 显示错误提示，表单内容保留
- **权限处理**：UNAUTHENTICATED → 跳转登录；NOT_CLUB_LEADER/CLUB_CANCELLED → 跳转学生首页

### 导航入口

在 `LeaderClubWorkspaceView` 中新增 "AI 文档生成" 导航卡片（位于内容举报管理卡片之后），点击跳转至 AI 文档生成页面。

## 6. 实现细节

### 后端

- 复用 S17 的 `_call_deepseek()` 函数调用 DeepSeek API
- 新增 `_AI_DOC_SYSTEM_PROMPT` 系统提示词（文档撰写助手角色）
- 新增 `_build_document_user_prompt(club, document_type, body)` 构建用户提示词
  - 自动补充社团名称、类别、简介
  - 按需拼接用户输入的 9 个可选字段
  - 超长内容按 `AI_MAX_CONTENT_CHARS` 截断
- 新增 `leader_ai_documents(request, club_id)` 视图函数
  - `@require_POST` 限制 POST
  - 调用 `require_leader_of_club` 校验负责人权限
  - 校验 `document_type` 白名单
  - 返回 `{"draft": answer}`

### 前端

- 新增类型：`AiDocumentType`、`AI_DOCUMENT_TYPES`、`GenerateAiDocumentInput`、`GenerateAiDocumentResponse`
- 新增 API 函数：`generateAiDocument(clubId, input)`
- 新增页面组件：`LeaderAiDocumentsView.vue`（独立子页面，类似 LeaderReportsView）
- 新增路由：`/leader/clubs/{id}/ai-documents`
- 新增导航入口卡片

## 10. 临时技术决定

- 系统提示词要求 AI "无法确定时用 [此处需要补充] 标记，不要编造"（与 S17 的严格限制不同，更适用于文档生成场景）
- 前端将空字符串的 optional 字段转为 `undefined`，避免发送无意义的空值到 AI prompt
- 生成按钮文案在已有草稿时显示"重新生成"（符合 API 设计——每次调用独立，不设独立重新生成接口）
