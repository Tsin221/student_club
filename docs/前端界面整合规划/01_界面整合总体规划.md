# 前端界面整合总体规划

## 文档信息

- **文档目的**：在不新增业务功能的前提下，对现有全部页面进行整合整理，统一布局结构，提升界面美观度和可读性。
- **设计基线**：`docs/阶段一_系统设计/06_页面菜单与路由设计.md`（页面清单与路由）、`docs/阶段一_系统设计/01_角色权限矩阵.md`（权限边界）。
- **当前状态**：草稿。
- **前置条件**：所有现有功能页面已完成开发（S00-S20），本规划只涉及前端界面层面的重构整合，不修改后端 API、数据库或业务逻辑。

### 1.2 当前架构问题

1. **无共享布局**：每个视图文件各自复制 `<main>`、`<header>`、内容容器，导致 28 个文件中有 28 份重复的布局代码。
2. **无侧边导航**：学生端用一行按钮切换页面，管理员端用卡片网格，负责人端把所有功能塞进一个超大组件。缺乏统一的侧边栏导航体系。
3. **CSS 类名混乱**：管理员页面复用 `.student-page` 类名，实际含义与实际角色不符。
4. **负责人工作台过于臃肿**：`LeaderClubWorkspaceView.vue` 包含了概览、社团资料编辑、成员管理、公告管理、反馈管理、帖子管理共六大块逻辑，单文件代码量极大。
5. **社团内部页面缺失**：根据设计文档，社团内部公告页（`/student/clubs/:clubId/inside/announcements`）、讨论板（`/student/clubs/:clubId/inside/posts`）、帖子详情（`/student/posts/:postId`）尚未实现独立视图文件。
6. **导航不直观**：用户在深层页面时无法知道自己身处何处，缺乏面包屑或侧边栏高亮。

## 2. 整合目标

1. **统一布局框架**：提取共享的页面外壳（Shell），包含顶栏、侧边栏、内容区，按角色提供不同外壳。
2. **侧边导航体系**：用侧边栏取代散落的按钮行和卡片网格，菜单项高亮当前所在页面。
3. **拆分臃肿组件**：将 `LeaderClubWorkspaceView.vue` 拆分为独立的子页面，通过侧边栏组织。
4. **补全缺失页面**：为社团内部公告、讨论板、帖子详情创建独立视图。
5. **视觉提升**：在现有蓝白色系基础上，增强信息层次、间距节奏、卡片质感。
6. **保持零新功能**：所有页面操作、API 调用、权限校验与现有一致，只改 UI 层面。

### 3.1 三层外壳设计

```
┌──────────────────────────────────────────────┐
│  顶栏（TopBar）                                │
│  [Logo] 系统名称    [社团切换]    [用户/退出]    │
├────────┬─────────────────────────────────────┤
│ 侧边栏  │                                      │
│        │         内容区（Content）               │
│ 菜单1  │                                      │
│ 菜单2  │     ┌──────────────────────┐         │
│ 菜单3  │     │  页面标题 + 面包屑     │         │
│ 菜单4  │     ├──────────────────────┤         │
│        │     │                      │         │
│        │     │   页面主体内容         │         │
│        │     │                      │         │

├────────┴─────────────────────────────────────┤

└──────────────────────────────────────────────┘
```

### 3.2 三种角色外壳

| 外壳 | 适用角色 | 特点 |
|------|---------|------|
| **AuthShell** | 未登录用户 | 无顶栏/侧边栏，左右分栏布局（品牌区 + 表单区），与现有登录/注册页一致 |
| **StudentShell** | 学生用户 | 顶栏 + 左侧学生菜单 + 内容区；进入社团内部时侧边栏切换为社团菜单 |
| **AdminShell** | 系统管理员 | 顶栏 + 左侧管理员菜单 + 内容区 |

### 3.3 顶栏设计

```
┌──────────────────────────────────────────────────────────────┐
```

- 右侧：用户头像/姓名，下拉菜单（个人中心 / 退出登录）

| 警告 | Element Plus 默认 | 待审核标签 |

### 6.2 排版节奏

| 元素 | 规格 |
|------|------|
| 页面标题 | 24px / 700 字重 / `#17233d` |
| 板块标题 | 18px / 600 字重 |
| 正文 | 14px / 400 字重 / `#17233d` |
| 说明文字 | 13px / `#64748b` |

### 6.3 卡片与间距

- 卡片使用白色背景 + 1px `#dce5f0` 边框 + 8px 圆角 + 无阴影（hover 时轻微阴影）
- 卡片之间间距 16-20px
- 内容区上下内边距 32px
- 面包屑与标题间距 12px，标题与内容间距 20px

### 6.4 图标

- 侧边栏菜单项使用 Element Plus 内置图标（`User`、`Edit`、`School`、`Document`、`Bell` 等）
- 统计卡片使用浅色圆形图标背景
