## 关键实现细节

### 申请提交校验顺序
1. 认证 + 正常学生账号
2. 招新存在且所属社团正常
3. 招新动态状态为"进行中"
4. 申请人不在该社团（无 active 成员关系）
5. 无重复待审核申请
6. 被拒绝后只能申请后续新招新（按 `published_at` 比较）
7. 创建申请时复制 `name` 和 `major_class` 快照

### 通过申请的原子事务
1. `select_for_update` 锁定招新记录
2. 重新检查容量、申请人账号和成员状态
3. 更新申请状态为"已通过"
4. `get_or_create` 成员关系 → 恢复或创建为"在社、普通成员"
5. 生成 `我的入社申请已经审核` 通知

### 通知生成规则
- 只在 S07 中实现 `我的入社申请已经审核` 类型
- `有人回复了我的帖子` 和 `我的举报已经处理` 将在 S11、S15 实现
- 通知无已读状态，不设分页
